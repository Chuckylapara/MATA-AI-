# NEXUS — Social media

**Status: planned (Phase 13).** The Social panel lists each platform's real status
(PLANNED / NOT CONFIGURED) with setup steps. `social_publish` exists as a HIGH-risk tool that
returns *integration not configured* — nothing is simulated.

Official APIs only: YouTube Data API v3, Instagram Graph API (business/creator), TikTok Content
Posting API (requires approval), X API (paid). Planned control center: accounts, drafts,
scheduled, published, analytics, comments, messages. Drafting captions/hashtags already works
through normal conversation.
